Coree-Template Documentation v1.0.0

Thank you for purchasing Coree-Template! This is a high-performance, enterprise-ready e-commerce ecosystem built with Node.js and Next.js.

🛠️ Tech Stack

  • Backend: Node.js (Express v5), Prisma, PostgreSQL
  • Frontend: Next.js 15 (App Router), Tailwind CSS v4
  • State: Zustand & TanStack Query v5
  • Payments: Paystack & Pay on Delivery

🚀 Quick Installation

Follow these steps to get your store online in minutes:

# 1. Install Backend
cd backend
npm install

# 2. Setup Database
npx prisma migrate dev
npx prisma db seed

# 3. Install Frontend
cd project-core-frontend
npm install

🔐 Environment Setup

Rename .env.example to .env in both folders and add your credentials:

  • DATABASE_URL: Your PostgreSQL connection string.
  • PAYSTACK_SECRET_KEY: From your Paystack dashboard.
  • CLOUDINARY_CLOUD_NAME: For image storage.

🌱 Sample Data (Seeding)

Run npx prisma db seed in the backend folder to instantly populate your store with:

  • Admin Account: admin@example.com / password123
  • Sample Products: Jewelry, Watches, and Accessories.
  • Analytics: Dummy orders to see your dashboard charts in action.
